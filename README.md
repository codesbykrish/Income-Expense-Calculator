# Income/Expense Calculator

## Description

The Income/Expense Calculator is a Python program that helps users analyze their monthly income and spending habits.

The program allows users to enter financial transactions by category, description, and amount. It calculates total income, total expenses, and the user's net balance.

The program also determines whether the user is within a predefined budget limit and identifies the category with the highest expenses.

## Features

- Calculates total monthly income
- Calculates total monthly expenses
- Calculates net balance
- Tracks expenses by category
- Identifies the highest expense category
- Checks whether spending is over the budget limit
- Generates a `budget_report.txt` file
- Allows users to analyze multiple sets of transactions

## How to Run

1. Download or clone this repository.
2. Open `cps109_a1.py` using Python IDLE.
3. Run the program.
4. Enter your income and expenses when prompted.
5. Type `done` when you have finished entering transactions.
6. The program will display a financial summary and create a budget report.

## Budget Limit

The program uses a predefined monthly budget limit of **$2,000**.
